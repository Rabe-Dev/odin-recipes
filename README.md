Vegan Bites (Odin Recipes) 🌱

This is my first web project built from scratch using my own code. I created it as part of The Odin Project to put the fundamentals of web development into practice.
About the Project
Vegan Bites is a plant-based recipe website featuring a collection of vegan recipes. The project allows me to apply what I learn while gradually building a functional and visually appealing website.
Technologies
    • HTML – Structuring the website and its content
    • CSS – Styling, layout, colors, and responsive design
Current Progress
The website includes multiple recipe pages and a recipe overview with preview cards. I have also made several CSS improvements to refine the layout, styling, and navigation menu.
What's Next?
The project is still a work in progress. My next steps are to continue improving the design, make the website fully responsive, and introduce JavaScript to add interactivity.
I'm using this project to strengthen my web development skills, experiment with new techniques, and learn by building something from the ground up.
